# 🤖 JARVES Command Center - Enterprise AI Operating System

Sistema Operacional Pessoal & Centro de Comando com Inteligência Artificial contextual, modelo 3D Spline interativo, comandos de voz neurais, automação no WhatsApp e ecossistema de 14 integrações empresariais.

---

## 🌟 Recursos Principais

- **🤖 Robô 3D Interativo em Tempo Real**: Avatar cibernético renderizado em WebGL/Spline com reações de fala e escuta.
- **🎙️ Motor de Voz Neural & Conversação Contínua**:
  - Voz idêntica ao JARVIS (ElevenLabs / OpenAI TTS / Web Speech Natural).
  - Controle de gênero (Voz Masculina / Feminina) e modo de escuta contínua.
  - Reconhecimento e execução de comandos de voz em tempo real.
- **🔌 14 Integrações Empresariais**:
  - 📩 **Emails Corporativos**: Gmail (Google Workspace) e Microsoft Outlook (365).
  - ☁️ **Nuvem & Documentos**: Google Drive e Microsoft OneDrive.
  - 💬 **Comunicação de Equipe**: WhatsApp Oficial (Áudios & Textos) e Microsoft Teams.
  - 📅 **Produtividade**: Google Calendar, Notion Database, Trello e GitHub.
  - ⚙️ **Automação & IoT**: n8n Webhooks, Home Assistant, Amazon Alexa e Google Home.
- **✅ Gestão de Tarefas & Prioridades**: Tarefas com prioridades, datas, categorias e filtros.
- **💰 Finanças & Múltiplas Carteiras**: Controle de patrimônio, fluxo de caixa e relatórios.
- **⚡ Hábitos & Streaks**: Matriz semanal de consistência e recordes de disciplina.
- **🎨 5 Temas Futuristas**: *Cyber Cyan, Neon Purple, Matrix Emerald, Titan Gold, Obsidian Dark*.

## 🚀 Como Executar Localmente

1. **Instalar dependências**:
   ```bash
   npm install
   ```

2. **Iniciar servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Gerar pacote de produção**:
   ```bash
   npm run build
   ```

## 🌐 Como Publicar na Web (Vercel / Netlify / GitHub)

### Opção 1: Publicação com 1 Clique na Vercel (Recomendado)
1. Crie um repositório no seu GitHub (ex: `jarves-enterprise-os`).
2. Suba o código:
   ```bash
   git init
   git add .
   git commit -m "feat: JARVES Enterprise AI Command Center"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```
3. Acesse [vercel.com](https://vercel.com) e clique em **Add New Project** -> **Import Git Repository**.
4. Clique em **Deploy**. Sua aplicação estará online com link HTTPS e SSL gratuito.
